# Habit Tracker
## Описание:
Проект представляет собой сервис для отслеживания привычек с системой напоминаний через Telegram и email.

Пользователь может создавать привычки, указывать время и место выполнения, а также получать автоматические уведомления о
необходимости выполнения.
## Функционал:
- Регистрация и авторизация пользователей
- CRUD для привычек
- Публичные и приватные привычки
- Пагинация списка привычек
- Валидация бизнес-логики привычек
- Отправка уведомлений через Telegram и email
- Асинхронные задачи через Celery
## Установка и использование:
1. Откройте PyCharm
2. Клонируйте репозиторий:
```
git clone https://github.com/svetlana-rogova/habit_tracker
```
3. Установите зависимости через Poetry:
```
poetri install
```
4. Активируйте виртуальное окружение:
```
poetry shell
```
5. Запустите проект:
```
python manage.py migrate
python manage.py runserver
```
## Структура проекта:

- tracker/ — логика привычек
- user/ — пользователи
- config/ — настройки проекта

## Тестирование:
Все тесты лежат в модуле tracker/tests.py, имена функций начинаются с test_.
Запустить тесты можно через команду pytest в терминале:
```
python manage.py test
```

Проверить покрытие можно через команду:
```
coverage report
```
## Права доступа:

- Пользователь видит только свои привычки
- Публичные привычки доступны всем
- Редактирование и удаление — только владельцу

## Уведомления:

Напоминания о привычках отправляются автоматически через:
- Telegram Bot
- Email

Используется Celery для асинхронной обработки задач.

## Бизнес-логика:

- Время выполнения ≤ 120 секунд
- Нельзя одновременно указать вознаграждение и связанную привычку
- Связанная привычка может быть только "приятной"
- Периодичность: не реже 1 раза в 7 дней

## API:

- POST /users/register/
- POST /users/login/

- GET /habits/ — список своих привычек
- POST /habits/ — создание привычки
- PUT /habits/{id}/ — обновление
- DELETE /habits/{id}/ — удаление
- GET /habits/public/ — публичные привычки

- Telegram Bot API
